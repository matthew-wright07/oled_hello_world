# Writing Hello World To An OLED Display With An ESP32

## Just figuring out the basics of sending output to displays with an ESP32

Basic program that uses external libraries and drivers to properly send output to the oled display

## Running it

To run the program compile and flash it to your ESP32 (and make sure your circuit is wired properly to handle the output) after flashing it just restart your ESP32 and watch Hello World be written to the OLED
